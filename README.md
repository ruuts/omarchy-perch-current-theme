# Perch Current

A personal Omarchy theme inspired by predator fishing on the IJssel and a
photograph of an old pine taken in Japan. River greens, warm bone, quiet
chartreuse accents, and an original perch emblem.

![Perch Current wallpaper](preview.png)

## The baseline

- **Quiet accents:** 2-pixel softened chartreuse window borders (`#AEBF70`).
- **Rounded surfaces:** 8-pixel corners and light compositor blur.
- **Terminal backgrounds:** 92% opacity; foreground text retains its own color.
- **Quickshell:** matching menus, launcher, shared plugin panels, notifications
  and tooltips with 94% background opacity.
- **Neovim:** Aether-based syntax, quiet tabs/statusline, and blended indentation
  guides (`#40584C`, with current scope `#5A715E`).
- **OpenCode:** 50 explicit semantic, syntax, Markdown, and diff colors.
- **Codex CLI:** follows the terminal palette through its built-in ANSI theme.
- **Wallpaper:** approved Upscayl High Fidelity result at 5120 × 2880.

## Install on another Omarchy machine

Requires **current Omarchy with Lua Hyprland configuration and the Quickshell
shell**, plus Python 3.11 or newer. The wallpaper and ready-to-use theme files
are included: no build tools, image generator, or Upscayl installation is needed.

Clone or copy this repository to that machine, open an **unlocked desktop
terminal**, then run from the repository directory:

```bash
python3 install.py --activate
```

To include the perch menu emblem:

```bash
python3 install.py --activate --perch-menu
```

`--perch-menu` uses Omarchy's plugin-cloning command and your current username.
It preserves the bar position and other widgets. If you already have a personal
menu customization, install without this option and merge `perch-menu.qml`
manually. Plugin changes can reload the shell: keep the desktop unlocked during
this step. A lock-recovery failure occurred during the original development
when a plugin was reloaded while the session was locked.

### What the installer does

1. Backs up existing destinations under
   `~/.local/state/perch-current/backups/<timestamp>/`, including a manifest.
2. Copies `theme/` to `~/.config/omarchy/themes/perch-current/` as a **plain
   user-owned directory**, preserving the custom Neovim and terminal files.
3. Installs `~/.config/opencode/themes/perch-current.json`.
4. With `--activate`, applies the Omarchy theme and selects Perch Current in
   OpenCode's `tui.json`, preserving other JSON settings.
5. If a Codex configuration exists, changes only `tui.theme` to `"ansi"`.
6. If the recognized optional Neovim transparency script exists, makes it skip
   Perch Current while preserving its behavior for other themes.

Restart **OpenCode, Neovim, and Codex** after installation; open a new **Foot**
window for background transparency. Your Neovim must load Omarchy's active
`neovim.lua` (the standard Omarchy setup does). Separate custom Neovim or project
OpenCode overrides can take precedence. OpenCode theme choice lives in `tui.json`;
if a `tui.jsonc` or project setting overrides it, use `/theme` in that context.

To install the files without changing the current desktop or app selections:

```bash
python3 install.py
```

Use this installer rather than passing the repository to `omarchy theme install`:
the payload is under `theme/`, and a Git-installed theme's Lua/terminal files can
be regenerated by Omarchy, losing these refinements.

### Transferring a local Git bundle

A bundle can move this repository without a hosting service:

```bash
# On the source machine, inside this repository:
git bundle create ../perch-current.bundle --all

# Copy the bundle to the other machine, then:
git clone ~/Downloads/perch-current.bundle ~/Projects/perch-current
cd ~/Projects/perch-current
python3 install.py --activate --perch-menu
```

Choose paths whose parent directories exist. A bundle is a snapshot; create a
new one to transfer later commits. If you host this repository later, normal
`git clone <repository-url>` and `git pull` work too.

### Switching themes and undoing installation

```bash
omarchy theme set <another-installed-theme>
```

The perch clone returns to its stock emblem when another theme is active.
Codex ANSI colors follow the terminal. If your Omarchy setup does not sync
OpenCode automatically, select its `system` theme with `/theme` when switching
away. This installer does not replace existing automation hooks.

For full rollback, the backup manifest lists every changed file and its saved
copy. Restore configuration from that snapshot while unlocked; a null backup
means the file did not previously exist. Files and directories are retained in
the backup even on repeated installation.

## Development

The committed `theme/` is the installation payload. `palette.json` and
`build-theme.py` maintain its colors and app-specific settings. Development
requires current Omarchy, Python with Pillow, Neovim with Aether already
installed, and LuaJIT.

```bash
python3 build-theme.py
python3 validate-theme.py
python3 -m unittest discover -s tests -v
```

The builder writes only into this checkout. It preserves the committed AI
wallpaper when no optional 4× master is present. Validation runs real Omarchy
staging in a temporary home, parses generated configuration, checks the 5K
wallpaper, and verifies real Aether highlights including indentation guides.
Installer tests cover portability, configuration preservation, backups, and
locked-session refusal.

For an optional wallpaper rebuild after installing Upscayl:

```bash
omarchy pkg aur add upscayl-bin
bash tools/upscale.sh
```

See [ARTWORK.md](ARTWORK.md) for source dimensions and processing provenance.
Local working-session notes, backups, screenshots, and intermediate image files
are ignored by Git.
